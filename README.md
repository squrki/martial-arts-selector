# martial-arts-selector

## Live Demo

[View my project here](https://squrki.github.io/martial-arts-selector/)

## Problem

With the variety of martial arts styles in the world, how does a person choose which style to practice?

## Value

This webpage is designed to help a person select a style that is most appropriate for their particular needs and circumstances.

## Project Plan

I want to build a web page that will take input of a person's particular attributes and make suggestions of the most appropriate martial arts based on those attributes.

## Features

Which features are complete?

* Taking personal attributes
* Evaluating attributes, and assigning weights to those attributes for particular martial arts styles
* Making recommendations on styles based on those attributes.

Which features would you build next?

* Complete the API to get the list of local schools.
* Adding images representing the particular styles

## Mission Brief

People argue about which martial arts style is the best. But there is no singular answer to this question. Everyone has different wants and needs for their personal health and/or safety. The martial-arts-selector application is an attempt to give the user an opening idea into which martial art is best suited to their individual desires.
